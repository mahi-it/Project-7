# Project-7 Modular & Packager

### Introduction

The Multi-Utility Toolkit is a simple Python menu-driven program. It provides multiple utilities using Python's built-in modules and custom modules.

The program provides the following main functionalities:

1. Datetime and Time Operations
2. Mathematical Operations
3. Random Data Generation
4. Generate Unique Identifiers (UUID)
5. File Operations (Custom Module)
6. Explore Module Attributes using dir()
7. Exit

The program uses separate Python modules for different operations. The program continues running until the user selects the *Exit* option.

### Features

- Display the current date and time.
- Calculate the difference between two dates/times.
- Format dates into a custom format.
- Use a stopwatch and countdown timer.
- Calculate factorial and compound interest.
- Perform trigonometric calculations.
- Calculate areas of geometric shapes.
- Generate random numbers and random lists.
- Create random passwords.
- Generate random OTPs.
- Generate unique UUIDs.
- Create, write, read, and append files.
- Explore module attributes using `dir()`.
- Uses separate modules for different functionalities.
- Menu-driven interface.
- Allows multiple operations in one execution.
